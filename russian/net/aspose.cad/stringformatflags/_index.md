## StringFormatFlags enumeration

Указывает информацию о отображении и размещении текстовых строк.

```csharp
[Flags]
public enum StringFormatFlags
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| DirectionRightToLeft | `1` | Текст отображается справа налево. |
| DirectionVertical | `2` | Текст выровнен по вертикали. |
| FitBlackBox | `4` | Разрешено, чтобы части символов выступали за пределы прямоугольника размещения строки. По умолчанию символы переустанавливаются, чтобы избежать любого выступания. |
| DisplayFormatControl | `20` | Управляющие символы, такие как маркер слева направо, отображаются в выводе с соответствующим глифом. |
| NoFontFallback | `400` | Запасные альтернативные шрифты для символов, не поддерживаемых запрошенным шрифтом, отключены. Любые отсутствующие символы отображаются глифом отсутствующего шрифта, обычно открытым квадратом. |
| MeasureTrailingSpaces | `800` | Включает завершающий пробел в конце каждой строки. По умолчанию граничный прямоугольник, возвращаемый методом MeasureString, исключает пробел в конце каждой строки. Установите этот флаг, чтобы включить этот пробел в измерения. |
| NoWrap | `1000` | Перенос текста между строками при форматировании внутри прямоугольника отключен. Этот флаг подразумевается, когда вместо прямоугольника передается точка или когда указанный прямоугольник имеет нулевую длину строки. |
| LineLimit | `2000` | В прямоугольнике форматирования размещаются только целые строки. По умолчанию разметка продолжается до конца текста или пока видимы строки, пока они не обрезаются, в зависимости от того, что наступит первым. Обратите внимание, что настройки по умолчанию позволяют последней строке быть частично скрытой прямоугольником форматирования, который не является целым кратным высоте строки. Чтобы гарантировать отображение только целых строк, укажите это значение и будьте внимательны, предоставляя прямоугольник форматирования как минимум высотой одной строки. |
| NoClip | `4000` | Разрешено отображать выступающие части глифов и не перенесённый текст, выходящий за пределы прямоугольника форматирования. По умолчанию весь текст и части глифов, выходящие за пределы прямоугольника форматирования, обрезаются. |

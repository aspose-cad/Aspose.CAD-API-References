## CadSectionViewStyle.Flags property

Флаги: 1: непрерывная маркировка, 2: показывать наконечники стрелок, 4: показывать метку вида, 8: показывать все линии плоскости,
0x10: показывать все конечные идентификаторы, 0x20 показывать линии концов и изгибов, 0x40: показывать штриховку

public int Flags { get; set; }

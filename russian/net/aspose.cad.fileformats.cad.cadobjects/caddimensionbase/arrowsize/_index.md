## CadDimensionBase.ArrowSize property

Получает или задает размер стрелки.
Оценивается по размеру твердого (вставляемого) объекта, представляющего стрелку.
Включён общий коэффициент масштабирования размера.
Установка нового размера обновляет соответствующие поля в XData для размера и изменяет связанные твердые (вставляемые) объекты.

```csharp
public double ArrowSize { get; set; }
```

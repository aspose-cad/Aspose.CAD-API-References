## CadEntityBase.LType property

Получает или задает значение текущего типа линии сущности.

```csharp
public byte LType { get; set; }
```

### Property Value

0 - ByLayer,

1 - ByBlock,

2 - Continuous,

3 - Установить на основе `LTYPE` объекта

## Примечания

Это свойство всегда равно 0 для версий старее `AC1015`.

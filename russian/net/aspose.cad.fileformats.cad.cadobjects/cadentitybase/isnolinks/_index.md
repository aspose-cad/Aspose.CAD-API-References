## CadEntityBase.IsNoLinks property

Получает или задает значение, указывающее, что у сущности нет ссылок.

```csharp
public bool IsNoLinks { get; set; }
```

### Property Value

`true`, если объект не имеет ссылок.

## Примечания

Для версий `AC1018` и более новых это значение всегда `true` (ссылки не используются).

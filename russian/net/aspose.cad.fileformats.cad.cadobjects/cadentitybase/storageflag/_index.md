## CadEntityBase.StorageFlag property

Получает или задает значение, указывающее, что у этой сущности есть связанные бинарные данные в хранилище данных.

```csharp
public override bool StorageFlag { get; set; }
```

### Property Value

`true`, если у сущности есть связанные бинарные данные.

## Примечания

Этот флаг всегда имеет значение false для `AC1024` и более ранних версий.

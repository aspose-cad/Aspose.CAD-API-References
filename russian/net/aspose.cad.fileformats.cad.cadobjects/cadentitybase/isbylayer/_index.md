## CadEntityBase.IsByLayer property

Получает или задает значение, указывающее, что тип линии сущности задается слоем.

```csharp
public bool IsByLayer { get; set; }
```

### Property Value

`true`, если тип линии сущности установлен по слою.

## Примечания

Этот флаг всегда false, за исключением версий `AC1012` и `AC1014`.

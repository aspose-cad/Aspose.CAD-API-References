## CadEntityBase.XDirMissingFlag property

Получает или задает значение, указывающее, что для этой сущности не хранится дескриптор XDictionary.

```csharp
public bool XDirMissingFlag { get; set; }
```

### Property Value

`true`, если у сущности нет дескриптора XDictionary.

## Примечания

Этот флаг всегда имеет значение false для `AC1015` и более ранних версий.

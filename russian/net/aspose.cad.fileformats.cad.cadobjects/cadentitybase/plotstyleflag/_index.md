## CadEntityBase.PlotStyleFlag property

Получает или задает значение текущего стиля печати сущности

```csharp
public byte PlotStyleFlag { get; set; }
```

### Property Value

0 - ByLayer,

1 - ByBlock,

3 - Установить на основе `PLACEHOLDER` объекта

## Примечания

Это свойство всегда равно 0 для версий старее `AC1015`.

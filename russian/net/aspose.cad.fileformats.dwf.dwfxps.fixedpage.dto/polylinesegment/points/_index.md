## PolyLineSegment.Points property

Получает или задает точки.
Указывает набор координат для нескольких сегментов, определяющих
полилинейный сегмент. Значения координат в каждой паре разделяются запятыми
и может появляться дополнительный пробел.
Пары координат разделяются пробелами.

public string Points { get; set; }

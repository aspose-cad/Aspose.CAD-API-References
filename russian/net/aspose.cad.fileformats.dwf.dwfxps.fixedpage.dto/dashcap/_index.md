## DashCap enumeration

Конец штриха.
Эффективное преобразование рендеринга пути, который обводится, используется
для преобразования контрольных точек контура штриха.

```csharp
public enum DashCap
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Flat | `0` | Плоский. Длина штриха — приблизительное расстояние по кривой между двумя точками пересечения плоских линий, завершающих штрих, и контуром фигуры. Расстояние от конца одного штриха до начала следующего штриха равно указанной длине промежутка между штрихами. Штрихи длиной более 0 рисуются, а вырожденные штрихи длиной 0 не рисуются. |
| Round | `1` | Круглый. Длина штриха — приблизительное расстояние по кривой между двумя точками пересечения контура, то есть пересечением плоской линии, завершающей штрих (без присоединённых круглых окончаний), и контура фигуры. Окончания рисуются как полукруги, присоединённые к концам штриха. Границы круглых окончаний не искажаются, чтобы следовать контуру, а преобразуются с помощью эффективного преобразования рендеринга. Расстояние между точками пересечения контура последовательных штрихов равно указанной длине промежутка между штрихами. Вырожденные штрихи длиной 0 рисуются как круги. |
| Square | `2` | Квадратный. Длина штриха — приблизительное расстояние по кривой между двумя точками пересечения контура, то есть пересечением плоской линии, завершающей штрих (без присоединённых квадратных окончаний), и контура фигуры. Окончания рисуются как полуквадраты, присоединённые к концам штриха. Границы квадратных окончаний не изогнуты, чтобы следовать контуру, а преобразуются с помощью эффективного преобразования рендеринга. Расстояние между точками пересечения контура последовательных штрихов равно указанной длине промежутка между штрихами. Вырожденные штрихи длиной 0 рисуются как квадраты. Если штрих длиной 0 появляется в месте соединения пути или очень близко к нему, различия в разрешении рендеринга и точности вычисления координат могут привести к различной ориентации окончаний штриха у разных потребителей. |
| Triangle | `3` | Треугольный. Длина штриха — приблизительное расстояние по кривой между двумя точками пересечения контура, то есть пересечением плоской линии, завершающей штрих (без присоединённых треугольных окончаний), и контура фигуры. Окончания рисуются как треугольники, присоединённые основанием к концам штриха. Границы треугольных окончаний не искажаются, чтобы следовать контуру, а преобразуются с помощью эффективного преобразования рендеринга. Высота треугольников составляет половину ширины линии. Расстояние между точками пересечения контура последовательных штрихов равно указанной длине промежутка между штрихами. Вырожденные штрихи длиной 0 рисуются как ромбы. Если штрих длиной 0 появляется в месте соединения пути или очень близко к нему, различия в разрешении рендеринга и точности вычисления координат могут привести к различной ориентации окончаний штриха у разных потребителей. |

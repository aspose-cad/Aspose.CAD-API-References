## VisualBrush.Viewbox property

Получает или задает область просмотра.
Указывает позицию и размеры исходного содержимого кисти.
Указывает четыре разделённых запятыми действительных числа (x, y, Width, Height), где ширина и высота неотрицательны.
Область просмотра определяет систему координат по умолчанию для элемента, указанного в свойстве VisualBrush.Visual.
Углы области просмотра сопоставляются с углами области вывода, тем самым обеспечивая обрезку и преобразование по умолчанию для исходного содержимого кисти.

public string Viewbox { get; set; }

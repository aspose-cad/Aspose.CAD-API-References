## VisualBrush.Viewport property

Получает или задает область просмотра.
Указывает регион в содержащем координатном пространстве основной плитки кисти, который
(возможно, повторно) применяется для заполнения области, к которой применяется кисть.
Указывает четыре действительных числа, разделённых запятыми (x, y, Width, Height), где ширина и высота неотрицательны.
Выравнивание шаблона кисти контролируется настройкой значений x и y.

```csharp
public string Viewport { get; set; }
```

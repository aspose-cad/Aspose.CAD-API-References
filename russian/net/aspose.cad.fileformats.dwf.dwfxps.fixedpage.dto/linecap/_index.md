## LineCap enumeration

Окончание линии.
Указывает внешний вид окончаний линий.

```csharp
public enum LineCap
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Flat | `0` | Плоская. Длина линии — приблизительное расстояние по кривой между двумя точками пересечения плоских линий, завершающих линию, и контуром фигуры. Линии длиной больше 0 рисуются, а вырожденные линии длиной 0 не рисуются. |
| Round | `1` | Круглая. Длина линии — приблизительное расстояние по кривой между двумя точками пересечения контура, то есть пересечение плоской линии, завершающей линию (без присоединённых круглых заглушек), и контура фигуры. Заглушки рисуются как полукруги, присоединённые к концам линии. Границы круглых заглушек не искажаются, чтобы следовать контуру, а трансформируются с помощью эффективного преобразования рендеринга. Вырожденная линия длиной 0 рисуется как круг. |
| Square | `2` | Квадратная. Длина линии — приблизительное расстояние по кривой между двумя точками пересечения контура, то есть пересечение плоской линии, завершающей линию (без присоединённых квадратных заглушек), и контура фигуры. Заглушки рисуются как полуквадраты, присоединённые к концам линии. Границы квадратных заглушек не изгибаются, чтобы следовать контуру, а трансформируются с помощью эффективного преобразования рендеринга. Вырожденные линии длиной 0 рисуются как квадраты. Если линия длиной 0 появляется в месте соединения или очень близко к нему в пути, различия в разрешении рендеринга и точности вычисления координат могут привести к различной ориентации заглушек линии у разных потребителей. |
| Triangle | `3` | Треугольная. Длина линии — приблизительное расстояние по кривой между двумя точками пересечения контура, то есть пересечение плоской линии, завершающей линию (без присоединённых треугольных заглушек), и контура фигуры. Заглушки рисуются как треугольники, присоединённые основанием к концам линии. Границы треугольных заглушек не искажаются, чтобы следовать контуру, а трансформируются с помощью эффективного преобразования рендеринга. Высота треугольников составляет половину ширины штриха. Вырожденные линии длиной 0 рисуются как ромбы. Если линия длиной 0 появляется в месте соединения или очень близко к нему в пути, различия в разрешении рендеринга и точности вычисления координат могут привести к различной ориентации заглушек линии у разных потребителей. |

## Overview

Пространство имён содержит сущности модели [FixedPage](./fixedpage/) DTO.

Часть [Aspose.CAD for .NET](../) справки API.

## Классы

| Класс | Описание |
| --- | --- |
| [ArcSegment](./arcsegment/) | Сегмент дуги. Представляет эллиптическую дугу между двумя точками. |
| [Brush](./brush/) | Кисть. Кисти используются для закраски внутренней части геометрических фигур, определённых элементом Path, и символов, отрисованных элементом Glyphs. Они также используются для определения маски альфа‑прозрачности в свойствах Canvas.OpacityMask, Path.OpacityMask и Glyphs.OpacityMask. |
| [Canvas](./canvas/) | Холст. Элемент Canvas группирует элементы вместе. Элементы Glyphs и Path могут быть сгруппированы в холсте, чтобы быть идентифицированными как единое целое (например, как назначение гиперссылки) или чтобы применить составное значение свойства к каждому дочернему и предшествующему элементу. |
| [FixedPage](./fixedpage/) | Фиксированная страница. Элемент FixedPage содержит содержимое страницы и является корневым элементом части FixedPage. Фиксированная страница содержит элементы, которые вместе образуют основу всех отметок, отрисовываемых на странице: Paths, Glyphs и необязательный элемент группировки Canvas. |
| [FixedPageFileParser](./fixedpagefileparser/) | Парсер файлов фиксированных страниц. Десериализует объекты DTO из XML‑файла FixedPage. |
| [Geometry](./geometry/) | Геометрия. Геометрии используются для построения визуального представления геометрических фигур. Наименьшая атомарная единица в геометрии — сегмент. Сегменты могут быть линиями или кривыми. Один или несколько сегментов объединяются в определение фигуры пути. Фигура пути — это единая форма, состоящая из непрерывных сегментов. Одна или несколько фигур пути совместно определяют всю геометрию пути. Геометрия пути МОЖЕТ определять алгоритм заполнения, используемый для компонентов фигур пути. |
| [Glyphs](./glyphs/) | Глифы. Элемент Glyphs представляет последовательность текста с единообразным форматированием из одного шрифта. Он предоставляет информацию, необходимую для точного рендеринга, и поддерживает функции поиска и выделения в потребителях просмотра. |
| [GradientStop](./gradientstop/) | Точка градиента. Элемент GradientStop используется элементами LinearGradientBrush и RadialGradientBrush для определения положения и диапазона изменения цвета при рендеринге градиента. Для линейных кистей градиента значение смещения 0.0 соответствует начальной точке градиента, а значение 1.0 — конечной точке. Промежуточные значения смещения интерполируются между этими двумя точками для определения их положения. Для радиальных кистей градиента значение смещения 0.0 соответствует месту происхождения градиента. Значение 1.0 соответствует окружности эллипса, определяемой центром, радиусом по оси X и радиусом по оси Y. Смещения между 0.0 и 1.0 располагаются в положении, интерполированном между этими точками. |
| [ImageBrush](./imagebrush/) | Кисть изображения. Элемент ImageBrush используется для заполнения области изображением. Изображение определяется в координатном пространстве, заданном разрешением изображения. Изображение ДОЛЖНО ссылаться на часть изображения JPEG, PNG, TIFF или JPEG XR внутри пакета документа. |
| [LinearGradientBrush](./lineargradientbrush/) | Линейная кисть градиента. Элемент LinearGradientBrush используется для указания линейной кисти градиента вдоль вектора. Заполняет область линейным градиентом. |
| [MatrixTransform](./matrixtransform/) | Матрица преобразования. Создаёт произвольное аффинное матричное преобразование, которое манипулирует объектами или координатными системами в двумерной плоскости. |
| [Path](./path/) | Путь. Определяет один графический эффект, который будет отрисован на странице. Он закрашивает геометрию кистью и рисует обводку вокруг неё. |
| [PathFigure](./pathfigure/) | Фигура пути. Элемент PathFigure состоит из набора одного или нескольких линейных или криволинейных сегментов. Сегментные элементы определяют форму фигуры пути. Начальная точка первого сегмента указывается атрибутом StartPoint фигуры пути. Последняя точка каждого сегмента является первой точкой следующего сегмента. |
| [PathGeometry](./pathgeometry/) | Геометрия пути. Элемент PathGeometry содержит набор фигур пути, указанных либо атрибутом Figures, либо дочерним элементом PathFigure. Производители НЕ ДОЛЖНЫ указывать фигуры пути геометрии одновременно с атрибутом Figures и дочерним элементом PathFigure. |
| [PolyBezierSegment](./polybeziersegment/) | Полигональный сегмент Безье. Последовательность сегментов BÉZIER. |
| [PolyLineSegment](./polylinesegment/) | Полилинейный сегмент. Указывает набор точек, между которыми рисуются линии. |
| [PolyQuadraticBezierSegment](./polyquadraticbeziersegment/) | Полигональный квадратичный сегмент Безье. Последовательность квадратичных сегментов BÉZIER. |
| [RadialGradientBrush](./radialgradientbrush/) | Радиальная градиентная кисть. |
| [ResourceDictionary](./resourcedictionary/) | Словарь ресурсов. Элементы свойства FixedPage.Resources и Canvas.Resources содержат ровно один элемент ResourceDictionary. Словарь ресурсов содержит записи элементов определений ресурсов. Каждый определение ресурса имеет ключ, указанный в атрибуте x:Key, который уникален в пределах словаря ресурсов. Атрибут x:Key включён в словарь ресурсов. |
| [Resources](./resources/) | Ресурсы. Элементы Canvas и FixedPage могут содержать словарь ресурсов. Словарь ресурсов задаётся в разметке элементом свойства FixedPage.Resources или Canvas.Resources. Отдельные значения ресурсов ДОЛЖНЫ быть указаны внутри словаря ресурсов. |
| [SolidColorBrush](./solidcolorbrush/) | Сплошная цветовая кисть. Элемент SolidColorBrush используется для заполнения определённых геометрических областей сплошным цветом. Если у цвета есть альфа‑компонент, он комбинируется мультипликативно с соответствующим атрибутом Opacity. |
| [Transform](./transform/) | Преобразование. Разметка документа OpenXPS поддерживает аффинные преобразования, задаваемые через свойства RenderTransform и Transform. Аффинное преобразование представлено списком из шести действительных чисел: m11, m12, m21, m22, OffsetX, OffsetY. Свойства RenderTransform и Transform оба задают аффинное матричное преобразование локального координатного пространства, используя элемент MatrixTransform в качестве значения. Сокращённый синтаксис матричного преобразования МОЖЕТ использоваться для указания значения атрибута RenderTransform или Transform. |
| [Visual](./visual/) | Визуальный элемент. Указывает элемент Path, Glyphs или Canvas, используемый для отрисовки визуального содержимого. |
| [VisualBrush](./visualbrush/) | Визуальная кисть. Элемент VisualBrush используется для заполнения области рисунком. Рисунок может быть указан либо как элемент свойства VisualBrush.Visual, либо как ссылка на ресурс. Содержимое рисунка может включать ровно один элемент Canvas, Path или Glyphs, а также дочерние и наследуемые элементы этого элемента. |

## Перечисление

| Перечисление | Описание |
| --- | --- |
| [ClrIntMode](./clrintmode/) | Режим CLR INT. Задает гамма‑функцию для интерполяции цвета. Коррекция гаммы не должна применяться к альфа‑компоненту, если он указан. |
| [DashCap](./dashcap/) | Конец штриха. Эффективное преобразование рендеринга пути, к которому применяется обводка, используется для преобразования контрольных точек контура штриха. |
| [EdgeMode](./edgemode/) | Режим краёв. EdgeMode может указывать рендерить содержимое элемента и всех дочерних и наследуемых элементов без выполнения сглаживания, включая дочерние кисти и их содержимое, а также содержимое, включённое через ссылки словаря ресурсов. |
| [FillRule](./fillrule/) | Правило заполнения. Атрибут FillRule задаёт алгоритм заполнения. Площадь заполнения геометрии определяется путем взятия всех содержащихся фигур пути и применения алгоритма заполнения для определения замкнутой области. Алгоритмы заполнения определяют, как пересекающиеся области геометрических фигур комбинируются в регион. |
| [LineCap](./linecap/) | Конец линии. Задает внешний вид окончаний линий. |
| [LineJoin](./linejoin/) | Стык линии. Задает внешний вид соединений линий. |
| [MappingMode](./mappingmode/) | Режим отображения. Указывает, что центр, радиус по оси X и радиус по оси Y определяются в эффективном координатном пространстве (включает атрибут Transform кисти). |
| [SpreadMethod](./spreadmethod/) | Метод распространения. Описывает, как кисть должна заполнять область содержимого за пределами основной, начальной области градиента. |
| [StyleSimulations](./stylesimulations/) | Симуляции стиля. Синтетические симуляции стиля могут применяться к форме глифов с помощью атрибута StyleSimulations. Симуляции стиля могут применяться в дополнение к разработанному стилю шрифта. Значение по умолчанию для атрибута StyleSimulations — None, в этом случае формы глифов не изменяются от их оригинального дизайна. |
| [SweepDirection](./sweepdirection/) | Направление sweep. Определяет, какая из двух возможных дуг (выбранных флагом Large Arc Flag) используется. Начиная с начальной точки, одна дуга движется в положительном (по часовой стрелке) направлении, а другая — в отрицательном (против часовой стрелки) направлении. |
| [TileMode](./tilemode/) | Режим тайлинга. Указывает, как выполняется заполнение геометрии плитками. |
| [ViewUnits](./viewunits/) | Единицы просмотра. Указывает соотношение координат просмотра к содержащему пространству координат. |

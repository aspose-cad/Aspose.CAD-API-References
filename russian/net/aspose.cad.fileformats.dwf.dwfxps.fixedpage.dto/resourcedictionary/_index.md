## ResourceDictionary class

Словарь ресурсов.
Элементы свойства [FixedPage](../fixedpage/).[Resources](../resources/) и [Canvas](../canvas/).[Resources](../resources/) содержат ровно один элемент ResourceDictionary.
Словарь ресурсов содержит элементы определений ресурсов.
Каждое определение ресурса имеет ключ, указанный в атрибуте x:Key, который уникален в пределах словаря ресурсов.
Атрибут x:Key включён в словарь ресурсов.

## Resources class

Ресурсы.
Элементы [Canvas](../canvas/) и [FixedPage](../fixedpage/) могут содержать словарь ресурсов.
Словарь ресурсов выражается в разметке элементом свойства [FixedPage](../fixedpage/).Resources или [Canvas](../canvas/).Resources.
Отдельные значения ресурсов ДОЛЖНЫ быть указаны в словаре ресурсов.

```csharp
public class Resources
```

## LinearGradientBrush.Transform property

Получает или задает преобразование.
Описывает матричное преобразование, применяемое к пространству координат кисти.
Свойство Transform кисти конкатенируется с текущим эффективным
преобразование рендеринга, чтобы получить эффективное преобразование рендеринга, локальное для кисти.
Точка начала и точка конца преобразуются с использованием локального эффективного преобразования рендеринга.

```csharp
public string Transform { get; set; }
```

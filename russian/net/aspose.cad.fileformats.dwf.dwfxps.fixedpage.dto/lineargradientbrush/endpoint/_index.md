## LinearGradientBrush.EndPoint property

Получает или задает конечную точку.
Указывает конечную точку линейного градиента.
Кисть линейного градиента интерполирует цвета от
точки начала до конечной точки, где точка начала
представляет смещение 0, а EndPoint представляет смещение 1.
Значение атрибута Offset, указанное в элементе GradientStop
соотносится со смещениями 0 и 1, определенными точкой начала и конечной точкой.

```csharp
public string EndPoint { get; set; }
```

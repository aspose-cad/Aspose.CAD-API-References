## LinearGradientBrush.LinearGradientBrushTransform property

Получает или задает преобразование кисти линейного градиента.
Описывает матричное преобразование, применяемое к пространству координат кисти.
Свойство Transform конкатенируется с текущим эффективным рендером
преобразованием, чтобы получить эффективное преобразование рендеринга, локальное для кисти.
Точка начала и точка конца преобразуются с использованием локального эффективного преобразования рендеринга.

```csharp
public Transform LinearGradientBrushTransform { get; set; }
```

## SweepDirection enumeration

Направление sweep.
Определяет, какая из двух возможных дуг (выбранных флагом Large Arc) используется.
Начиная с начальной точки, одна дуга движется в положительном (по часовой стрелке) направлении,
в то время как другая движется в отрицательном (против часовой стрелки) направлении.

```csharp
public enum SweepDirection
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Clockwise | `0` | По часовой стрелке. |
| Counterclockwise | `1` | Против часовой стрелки. |

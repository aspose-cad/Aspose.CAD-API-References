## Glyphs.FontUri property

Получает или задает URI шрифта.
URI физического шрифта, из которого берутся все глифы в последовательности. URI ДОЛЖЕН ссылаться на шрифт, содержащийся в пакете.
Если указанный физический шрифт является коллекцией TrueType (содержащей несколько начертаний),
фрагмент URI представляет собой нулевой индекс, указывающий, какое начертание коллекции TrueType следует использовать.

```csharp
public string FontUri { get; set; }
```

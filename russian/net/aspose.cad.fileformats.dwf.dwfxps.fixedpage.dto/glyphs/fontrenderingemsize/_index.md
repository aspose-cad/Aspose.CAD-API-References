## Glyphs.FontRenderingEmSize property

Получает или задает размер EM рендеринга шрифта.
Указывает размер шрифта в единицах поверхности рисования,
выраженный как число с плавающей запятой в единицах эффективного координатного пространства.
Значение 0 приводит к тому, что текст не виден.

```csharp
public double FontRenderingEmSize { get; set; }
```

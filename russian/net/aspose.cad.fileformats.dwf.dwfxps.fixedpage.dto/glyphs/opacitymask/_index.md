## Glyphs.OpacityMask property

Получает или задает маску непрозрачности.
Указывает маску альфа‑значений, которая применяется к глифам так же, как атрибут Opacity,
но позволяя использовать разные альфа‑значения для разных областей элемента.

```csharp
public string OpacityMask { get; set; }
```

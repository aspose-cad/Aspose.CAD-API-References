## Glyphs.UnicodeString property

Получает или задает строку Unicode.
Содержит строку текста, отрисованного элементом Glyphs.
Текст задаётся в виде кодовых точек Unicode.
Если атрибут UnicodeString элемента Glyphs не указан
или содержит пустое значение (“” или “{ }”), и если атрибут Indices не указан
или не содержит индексов глифов, тогда потребитель ДОЛЖЕН создать условие ошибки.

public string UnicodeString { get; set; }

## Glyphs.GlyphsRenderTransform property

Получает или задает преобразование рендеринга глифов.
Устанавливает новую систему координат для последовательности глифов, указанной элементом Glyphs.
Преобразование рендеринга влияет на обрезку, маску непрозрачности, заливку, координату x, координату y, фактическую форму отдельных глифов и ширину продвижения.
Преобразование рендеринга также влияет на размер шрифта и значения, указанные в атрибуте Indices.

```csharp
public Transform GlyphsRenderTransform { get; set; }
```

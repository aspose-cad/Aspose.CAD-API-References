## Glyphs.OriginX property

Получает или задает координату x начала.
Указывает координату x первого глифа в последовательности, в единицах эффективного координатного пространства.
Глиф размещается так, чтобы передний край его вектора продвижения и базовая линия пересекались
с точкой, определённой атрибутами OriginX и OriginY.

```csharp
public double OriginX { get; set; }
```

## Glyphs.RenderTransform property

Получает или задает преобразование рендеринга.
Устанавливает новую систему координат для последовательности глифов, указанной элементом Glyphs.
Преобразование рендеринга влияет на обрезку, маску непрозрачности, заливку, исходную точку по оси x, исходную точку по оси y, фактическую форму отдельных глифов,
и ширины продвижения. Преобразование рендеринга также влияет на размер шрифта и значения, указанные в атрибуте Indices.

public string RenderTransform { get; set; }

## Glyphs.Indices property

Получает или задает индексы.
Указывает серию индексов глифов и их атрибутов, используемых для отрисовки последовательности глифов.
Если атрибут UnicodeString элемента Glyphs не указан
или содержит пустое значение (“” или “{ }”), и если атрибут Indices не указан или не содержит индексов глифов,
тогда потребитель ДОЛЖЕН создать условие ошибки.

```csharp
public string Indices { get; set; }
```

## FillRule enumeration

Правило заливки.
Атрибут FillRule указывает алгоритм заливки.
Область заливки геометрии определяется путем взятия всех
содержащих фигур пути и применения алгоритма заливки для определения замкнутой области.
Алгоритмы заливки определяют, как пересекающиеся области геометрических фигур комбинируются для формирования региона.

```csharp
public enum FillRule
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| EvenOdd | `0` | Четный‑нечетный. Это правило определяет «ВНУТРЕННЮЮ ПРИНАДЛЕЖНОСТЬ» точки на холсте, проводя луч от точки до бесконечности в любом направлении и подсчитывая количество сегментов заданной формы, которые пересекает луч. Если это число нечетное, точка находится внутри; если четное — снаружи. Это правило используется по умолчанию во всей разметке документа. |
| NonZero | `1` | Ненулевой. Это правило определяет «ВНУТРЕННЮЮ ПРИНАДЛЕЖНОСТЬ» точки на холсте, проводя луч от точки до бесконечности в любом направлении, а затем исследуя места, где сегмент формы пересекает луч. Начиная с нулевого счёта, прибавляйте один каждый раз, когда сегмент пересекает луч слева направо, и вычитайте один каждый раз, когда сегмент пути пересекает луч справа налево. После подсчёта пересечений, если результат равен нулю, точка находится вне пути; иначе — внутри. |

## SolidColorBrush class

Одноцветная кисть.
Элемент SolidColorBrush используется для заполнения определённых геометрических областей одноцветным цветом.
Если у цвета есть альфа‑компонент, он комбинируется мультипликативно с соответствующим атрибутом Opacity.

```csharp
public class SolidColorBrush
```

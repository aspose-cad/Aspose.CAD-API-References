## Path.SnapsToDevicePixels property

Получает или задает значение, указывающее, привязывается ли к пикселям устройства.
При сглаживании потребители контролируют, если контрольные точки
привязываются к ближайшим пикселям устройства. Допустимые значения — ‘false’ и ‘true’.
Потребители МОГУТ игнорировать этот атрибут.

```csharp
public bool SnapsToDevicePixels { get; set; }
```

## Path.StrokeDashArray property

Получает или задает массив пунктиров штриха.
Указывает длину штрихов и промежутков контура штриха.
Эти значения задаются как кратные толщине штриха
в виде списка, разделённого пробелами, с чётным числом неотрицательных значений.
Когда штрих рисуется, штрихи и промежутки, указанные этими
значениями повторяются, чтобы покрыть длину штриха.
Если этот атрибут опущен, штрих рисуется сплошным, без каких-либо промежутков.

```csharp
public string StrokeDashArray { get; set; }
```

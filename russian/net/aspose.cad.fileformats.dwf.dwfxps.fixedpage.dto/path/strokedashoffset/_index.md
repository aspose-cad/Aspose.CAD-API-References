## Path.StrokeDashOffset property

Получает или задает смещение пунктирной линии.
Регулирует начальную точку повторения шаблона массива пунктиров.
Если это значение опущено, массив пунктиров выравнивается с началом штриха.
Значения указываются как кратные толщине штриха.

```csharp
public double StrokeDashOffset { get; set; }
```

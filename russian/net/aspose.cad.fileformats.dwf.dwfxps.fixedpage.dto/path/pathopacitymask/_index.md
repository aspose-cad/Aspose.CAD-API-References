## Path.PathOpacityMask property

Получает или задает маску непрозрачности пути.
Указывает маску альфа‑значений, применяемую к пути так же, как атрибут Opacity,
но позволяя использовать разные альфа‑значения для разных областей элемента.

```csharp
public Brush PathOpacityMask { get; set; }
```

## Path.StrokeLineJoin property

Получает или задает соединение линий штриха.
Указывает, как штрих рисуется на углу пути.
Допустимые значения: Miter, Bevel и Round.
Если выбран Miter, значение StrokeMiterLimit используется при рисовании штриха.

public LineJoin StrokeLineJoin { get; set; }

## Path.StrokeMiterLimit property

Получает или задает значение stroke miter limit.
Отношение между максимальной длиной среза и половиной толщины штриха.
Это значение имеет значение только если атрибут StrokeLineJoin указывает Miter.

```csharp
public double StrokeMiterLimit { get; set; }
```

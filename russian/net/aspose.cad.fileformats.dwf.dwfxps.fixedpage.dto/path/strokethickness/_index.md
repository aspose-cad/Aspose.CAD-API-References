## Path.StrokeThickness property

Получает или задает толщину штриха.
Указывает толщину штриха,
в единицах эффективного координатного пространства (включает трансформацию рендеринга пути).
Штрих рисуется поверх границы
геометрии, указанной свойством Data элемента Path.
Половина StrokeThickness выходит за пределы геометрии, указанной свойством Data.

```csharp
public double StrokeThickness { get; set; }
```

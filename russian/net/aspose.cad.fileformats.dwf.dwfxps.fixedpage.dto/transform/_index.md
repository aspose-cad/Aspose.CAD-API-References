## Transform class

Трансформ.
Разметка OpenXPS Document поддерживает аффинные преобразования, выраженные через
свойства RenderTransform и Transform. Аффинное преобразование представлено
в виде списка из шести действительных чисел: m11, m12, m21, m22, OffsetX, OffsetY.
Свойства RenderTransform и Transform оба задают аффинное матричное преобразование
в локальное координатное пространство, используя элемент [MatrixTransform](../matrixtransform/) в качестве их значения.
Сокращённый синтаксис матричного преобразования МОЖЕТ использоваться для указания значения атрибута RenderTransform или Transform.

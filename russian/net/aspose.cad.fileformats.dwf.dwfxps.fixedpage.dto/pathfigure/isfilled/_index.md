## PathFigure.IsFilled property

Получает или задает значение, указывающее, заполнен ли объект.
Указывает, используется ли фигура пути при вычислении площади
содержащей геометрии пути.
Может быть true или false.
Если установлено значение false, фигура пути учитывается только при обводке.

```csharp
public bool IsFilled { get; set; }
```

## RadialGradientBrush.Transform property

Получает или задает преобразование.
Описывает матричное преобразование, применяемое к пространству координат кисти.
Свойство Transform конкатенируется с текущим эффективным преобразованием рендеринга
чтобы получить эффективное локальное преобразование рендеринга для кисти.
Эллипс, определяемый центром, началом градиента, радиусом по x,
и значениями радиуса по y, преобразуется с использованием локального эффективного преобразования рендеринга.

```csharp
public string Transform { get; set; }
```

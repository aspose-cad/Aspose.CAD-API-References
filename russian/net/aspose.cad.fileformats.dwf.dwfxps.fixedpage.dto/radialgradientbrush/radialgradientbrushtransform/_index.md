## RadialGradientBrush.RadialGradientBrushTransform property

Получает или задает преобразование кисти радиального градиента.
Описывает матричное преобразование, применяемое к пространству координат кисти.
Свойство Transform конкатенируется с текущим эффективным преобразованием рендеринга
чтобы получить эффективное локальное преобразование рендеринга для кисти. Центр, начало градиента,
радиусы по x и y преобразуются с использованием локального эффективного преобразования рендеринга.

```csharp
public Transform RadialGradientBrushTransform { get; set; }
```

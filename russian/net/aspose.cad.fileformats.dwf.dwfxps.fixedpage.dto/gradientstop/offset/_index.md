## GradientStop.Offset property

Получает или задает смещение.
Указывает смещение градиента.
Смещение указывает точку вдоль прогрессии градиента, в которой задаётся цвет.
Цвета между смещениями градиента в прогрессии интерполируются.

public double Offset { get; set; }

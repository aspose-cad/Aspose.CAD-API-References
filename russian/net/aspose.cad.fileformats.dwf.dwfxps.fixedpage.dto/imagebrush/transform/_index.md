## ImageBrush.Transform property

Получает или задает преобразование.
Описывает матричное преобразование, применяемое к пространству координат кисти.
Свойство Transform конкатенируется с текущим эффективным рендером
преобразованием, чтобы получить эффективное преобразование рендеринга, локальное для кисти.
Область вывода кисти преобразуется с использованием локального эффективного преобразования рендеринга.

```csharp
public string Transform { get; set; }
```

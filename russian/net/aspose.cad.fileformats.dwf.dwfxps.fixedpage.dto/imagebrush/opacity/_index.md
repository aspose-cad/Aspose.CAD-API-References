## ImageBrush.Opacity property

Получает или задает непрозрачность.
Определяет единообразную прозрачность заполнения кисти.
Значения находятся в диапазоне от 0 (полностью прозрачный) до 1 (полностью непрозрачный),
включительно. Значения за пределами этого диапазона недействительны.

```csharp
public double Opacity { get; set; }
```

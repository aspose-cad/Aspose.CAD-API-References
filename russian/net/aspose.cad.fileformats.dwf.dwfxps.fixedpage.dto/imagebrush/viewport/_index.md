## ImageBrush.Viewport property

Получает или задает область просмотра.
Указывает регион в координатном пространстве контейнера
основной плитки кисти, который (возможно, повторно) применяется
для заполнения региона, к которому применяется кисть.
Указывает четыре действительных числа, разделённых запятыми (x, y, ширина, высота),
где ширина и высота неотрицательны. Выравнивание
рисунка кисти контролируется изменением значений x и y.

```csharp
public string Viewport { get; set; }
```

## ImageBrush.Viewbox property

Получает или задает область просмотра.
Указывает позицию и размеры исходного содержимого кисти.
Указывает четыре разделённых запятыми действительных числа (x, y, ширина, высота),
где ширина и высота неотрицательны.
Указанные размеры являются относительными к физическим размерам изображения, выраженным в единицах 1/96\".
Углы области просмотра отображаются на углы области вывода,
что обеспечивает стандартную обрезку и преобразование исходного содержимого кисти.

```csharp
public string Viewbox { get; set; }
```

## SpreadMethod enumeration

Метод распространения.
Описывает, как кисть должна заполнять область содержимого за пределами основной, начальной области градиента.

```csharp
public enum SpreadMethod
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Pad | `0` | Заполнение pad. В этом методе первый и последний цвет используются для заполнения оставшейся области в начале и в конце. |
| Reflect | `1` | Отражение (reflect). В этом методе остановки градиента воспроизводятся в обратном порядке неоднократно, чтобы покрыть область заполнения. |
| Repeat | `2` | Повтор (repeat). В этом методе остановки градиента повторяются по порядку, пока не будет покрыта область заполнения. |

## Canvas.RenderOptionsEdgeMode property

Получает или задает режим краев параметров рендеринга.
Управляет тем, как рендерятся края путей внутри канвы.
Единственное допустимое значение — Aliased.
Опущение этого атрибута приводит к рендерингу краев способом, установленным по умолчанию у потребителя.

```csharp
public EdgeMode RenderOptionsEdgeMode { get; set; }
```

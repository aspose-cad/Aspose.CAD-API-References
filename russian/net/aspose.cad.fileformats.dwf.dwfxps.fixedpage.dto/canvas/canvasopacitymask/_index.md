## Canvas.CanvasOpacityMask property

Получает или задает маску непрозрачности канвы.
Указывает маску альфа‑значений, которая применяется к канве так же, как атрибут Opacity,
но позволяя использовать разные альфа‑значения для разных областей элемента.

```csharp
public Brush CanvasOpacityMask { get; set; }
```

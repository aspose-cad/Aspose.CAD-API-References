## Canvas.Opacity property

Получает или задает непрозрачность.
Определяет равномерную прозрачность холста.
Значения находятся в диапазоне от 0 (полностью прозрачный) до 1 (полностью непрозрачный), включительно.
Значения вне этого диапазона недействительны.

```csharp
public double Opacity { get; set; }
```

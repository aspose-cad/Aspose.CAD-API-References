## FixedPage.FixedPageResources property

Получает или задает ресурсы фиксированной страницы.
Разметка фиксированной страницы поддерживает использование ресурсов.
Ресурс — это переиспользуемое значение свойства, выраженное в разметке, идентифицированное ключом и хранящееся в словаре ресурсов.
Как правило, любое значение свойства, которое может быть выражено с помощью синтаксиса элементов свойства, может храниться в словаре ресурсов.

```csharp
public Resources FixedPageResources { get; set; }
```

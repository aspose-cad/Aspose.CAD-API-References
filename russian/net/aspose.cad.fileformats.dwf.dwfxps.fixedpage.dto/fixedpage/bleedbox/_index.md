## FixedPage.BleedBox property

Получает или задает bleed box.
Указывает объединение ContentBox и ограничивающего прямоугольника всего графического контента, предназначенного для отображения в окончательной печатной
и обрезанной странице. Содержит список из четырёх координатных значений (BleedOriginX, BleedOriginY, BleedWidth, BleedHeight),
выраженных как числа с плавающей запятой, разделённые запятыми. Если опущено, значение по умолчанию — (0,0, Width, Height).

```csharp
public string BleedBox { get; set; }
```

## FixedPage.ContentBox property

Получает или задает область содержимого.
Указывает область страницы, содержащую графическое содержимое, которое должно быть вписано в область изображения
при печати или просмотре. Содержит список из четырёх координатных значений (ContentOriginX, ContentOriginY, ContentWidth, ContentHeight),
выражено как числа с плавающей запятой, разделённые запятыми. Указание значения РЕКОМЕНДУЕТСЯ. Если опущено, значение по умолчанию — (0,0,Width,Height).

```csharp
public string ContentBox { get; set; }
```

## PageSizingOptions.OverrideOutputUnitType property

Переопределяет единицы измерения выходного формата. Например, единицы PDF — пункты, которые равны 1/72 дюйма. Источник 1x1 дюйм будет экспортирован как 72x72 в PDF. Если OverrideOutputUnitType установить в Inch, вывод будет 1x1.

```csharp
public UnitType? OverrideOutputUnitType { get; set; }
```

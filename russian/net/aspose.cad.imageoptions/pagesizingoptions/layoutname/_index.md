## PageSizingOptions.LayoutName property

Имя страницы, к которой должны применяться эти параметры. Если NULL, то первый объект PageSizingOptions в списке будет применён к любым страницам, которые должны быть экспортированы, но не имеют PageSizingOptions с соответствующим именем.

```csharp
public string LayoutName { get; set; }
```

## PageSizingOptions.Margins property

Размер полей для текущей страницы. Если размер выходной страницы задаётся явно через Width\Height\Depth, поля вычитаются из размера. Если размер выходной страницы вычисляется из размера источника, поля добавляются.

```csharp
public Margins Margins { get; set; }
```

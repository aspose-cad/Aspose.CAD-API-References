## PageSizingOptions.SourceScaling property

На сколько следует увеличить размер источника, игнорируя единицы. Если источник 1x1 дюйм, а SourceScaling = 10, источник интерпретируется как 10x10 дюймов.

```csharp
public double SourceScaling { get; set; }
```

## PageSizingOptions.Zoom property

Это коэффициент масштабирования, позволяющий немного уменьшить рисунок, чтобы вертикальные и горизонтальные линии поместились на холсте.
Значение по умолчанию — 1 - (0.0026 * 2), потому что при выполнении команды ZOOM EXTENTS в Autocad оставляется примерно 0,26 % от каждой стороны в виде зазора.

```csharp
public double Zoom { get; set; }
```

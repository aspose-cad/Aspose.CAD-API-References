## RenderMode enumeration

Устанавливает, должен ли результат вывода для DXF/DWG быть векторизованным или растеризованным.

```csharp
public enum RenderMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Vector | `0` | Векторное качество, полезное для 2D каркасных чертежей. |
| Rasterized | `1` | Растровое качество, позволяет экспортировать 3D‑модели. |

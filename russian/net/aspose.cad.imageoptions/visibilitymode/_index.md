## VisibilityMode enumeration

Определяет проверку видимости сущностей — платформы CAD обычно позволяют отдельные видимости сущностей для печати и отображения на экране.

```csharp
public enum VisibilityMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| AsPrint | `0` | Отображать как печатное |
| AsScreen | `1` | Отображать как на экране |

## DxfOptions.ConvertMeshToLines property

Получает или задает значение, указывающее, следует ли
экспортировать в виде линий (каркас) вместо сущностей MESH, чтобы полученный DXF содержал только линии.
Включено по умолчанию: преобразование DWF в DXF никогда не создает сетки, если только это не установлено в `false`.

```csharp
public bool ConvertMeshToLines { get; set; }
```

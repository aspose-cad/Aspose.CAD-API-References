## NodeBuilder.SetLocalTransform method

Устанавливает локальное преобразование этого узла.
При необходимости можно сохранить дочерние элементы от влияния изменения преобразования этого узла.

```csharp
public void SetLocalTransform(AffineTransform newLocalTransform, bool keepChildrenInPlace)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| newLocalTransform | AffineTransform | новое локальное преобразование |
| keepChildrenInPlace | Boolean | true, чтобы сохранять дочерние элементы в их мировых позициях. |

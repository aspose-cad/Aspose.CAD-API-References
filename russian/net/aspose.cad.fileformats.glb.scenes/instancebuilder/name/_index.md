## InstanceBuilder.Name property

Получает отображаемое текстовое имя этого объекта или null.
 

**⚠️ DO NOT USE AS AN OBJECT ID ⚠️** see remarks.

```csharp
public string Name { get; }
```

## Примечания

glTF не определяет никаких правил для имен объектов.

Это означает, что имена могут быть null или не уникальными.

Поэтому не используйте имена ни для чего, кроме отображения имени объекта.

Если вам нужно ссылаться на объекты по какому‑то ID, используйте таблицы поиска.

## LightBuilder.Spot.Range property

Получает или задает подсказку, определяющую предельное расстояние, при котором
интенсивность света может считаться равной нулю.

Поддерживается только для точечных и прожекторных светильников. Должно быть &gt; 0.

Если не определено, диапазон считается бесконечным.

```csharp
public float Range { get; set; }
```

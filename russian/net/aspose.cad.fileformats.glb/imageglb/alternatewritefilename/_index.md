## ImageGlb.AlternateWriteFileName property

Когда устанавливается в FileName или относительный File Path,
оно будет использоваться как имя файла записываемой текстуры.

Если значение null, будет использовано имя файла по умолчанию.

```csharp
public string AlternateWriteFileName { get; set; }
```

## Примечания

если не уверены в расширении изображения, использование .* в качестве расширения заменит
расширение на соответствующее во время записи.
 
 

Для более сложных сценариев вы также можете использовать: `ImageWriteCallback`

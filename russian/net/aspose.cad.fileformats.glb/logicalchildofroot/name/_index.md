## LogicalChildOfRoot.Name property

Получает или задает отображаемое текстовое имя или null.
 

**⚠️ DO NOT USE AS AN OBJECT ID ⚠️** see remarks.

```csharp
public string Name { get; set; }
```

## Примечания

glTF не определяет никаких правил для имен объектов.

Это означает, что имена могут быть null или не уникальными.

Поэтому не используйте [`Name`](../name/) ни для чего, кроме отображения имени объекта.

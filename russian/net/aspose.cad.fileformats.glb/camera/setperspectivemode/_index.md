## Camera.SetPerspectiveMode method

Настраивает эту [`Camera`](../) для использования перспективной проекции.

```csharp
public void SetPerspectiveMode(float? aspectRatio, float yfov, float znear, float zfar)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| aspectRatio | Nullable`1 | Соотношение сторон между горизонталью и вертикалью. (необязательно) |
| yfov | Single | Вертикальное поле зрения в радианах. |
| znear | Single | Расстояние до ближней плоскости по оси Z. |
| zfar | Single | Расстояние до дальней плоскости по оси Z. |

## GlbData.LoadGlbImage method

Считывает экземпляр [`GlbData`](../) из пути, указывающего на файл GLB или GLTF

```csharp
public static GlbData LoadGlbImage(string filePath, ReadSettings settings = null)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| filePath | String | Допустимый путь к файлу. |
| настройки | ReadSettings | Опциональные настройки. |

### Возвращаемое значение

Экземпляр [`GlbData`](../).

## Примечания

*settings* can be either a plain [`ReadSettings`](../../readsettings/) instance,
или `ReadContext`, в этом случае контекст будет использоваться для чтения
файлов из него.

## PunctualLight.Range property

Получает или задает подсказку, определяющую предельное расстояние, при котором интенсивность света считается
равной нулю. Поддерживается только для точечных и прожекторных источников.
Если не определено, диапазон считается бесконечным.

```csharp
public float Range { get; set; }
```

## Overview

Пространство имён содержит классы для моделей STL.

Часть [Aspose.CAD for .NET](../) справки API.

## Классы

| Класс | Описание |
| --- | --- |
| [ColorDataUnit](./colordataunit/) | Настройте цвет поверхности. |
| [NormalDataUnit](./normaldataunit/) | Нормаль к поверхности. |
| [StlFace](./stlface/) | Представляет объект грани для изображения Stl. Он хранит индексы вершин, текстур и нормалей. |
| [StlRoot](./stlroot/) | Представляет корневую информацию для чертежа STL. StlRoot содержит данные о вершинах, материалах и формах. Каждая форма содержит информацию о наборе граней с соответствующим материалом, вершиной и индексами нормалей. |
| [StlShape](./stlshape/) | Представляет объект формы для формата Stl. Содержит информацию о наборе граней с соответствующим материалом, вершинами, текстурами и индексами нормалей. |
| [TriangularFacet](./triangularfacet/) | Треугольный фасет поверхности. |
| [VertexDataUnit](./vertexdataunit/) | Координаты вершин треугольных граней. |

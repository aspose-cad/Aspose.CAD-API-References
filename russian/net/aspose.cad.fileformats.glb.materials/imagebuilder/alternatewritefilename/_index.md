## ImageBuilder.AlternateWriteFileName property

Когда установлено в FileName или относительный File Path, оно будет использоваться для записи текстуры.

```csharp
public string AlternateWriteFileName { get; set; }
```

## Примечания

Если значение null, будет использовано имя файла по умолчанию.
 
 

если не уверены в расширении изображения, использование \".*\" в качестве расширения заменит
расширение на соответствующее перед записью.

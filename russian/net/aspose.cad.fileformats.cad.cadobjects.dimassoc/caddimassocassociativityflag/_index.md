## CadDimAssocAssociativityFlag enumeration

Указывает, какие точки измерения имеют ассоциативные ссылки. Несколько значений могут быть объединены.

```csharp
[Flags]
public enum CadDimAssocAssociativityFlag
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| FirstPointReference | `1` | Указывает, что первая точка имеет ассоциативную ссылку. |
| SecondPointReference | `2` | Указывает, что вторая точка имеет ассоциативную ссылку. |
| ThirdPointReference | `4` | Указывает, что третья точка имеет ассоциативную ссылку. |
| FourthPointReference | `8` | Указывает, что четвертая точка имеет ассоциативную ссылку. |

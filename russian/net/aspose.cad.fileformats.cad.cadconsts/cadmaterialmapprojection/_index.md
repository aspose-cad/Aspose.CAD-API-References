## CadMaterialMapProjection enumeration

Указывает метод проекции текстуры для [`CadMaterialMap`](../../../aspose.cad.fileformats.cad.cadobjects/cadmaterialmap/).

```csharp
public enum CadMaterialMapProjection : byte
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Inherit | `0` | Наследовать проекцию от родителя. |
| Planar | `1` | Отображает 2D-координаты изображения напрямую в координаты XY. |
| Box | `2` | Отображает 2D-координаты изображения на плоскость, нормальную к основной оси. |
| Cylinder | `3` | Отображает 2D-координаты изображения на цилиндр вдоль оси Z. |
| Sphere | `4` | Отображает 2D-координаты изображения на сферу с полюсами на оси Z. |

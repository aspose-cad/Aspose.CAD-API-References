## CadMaterialMode enumeration

Определяет режим рендеринга [`CadMaterial`](../../../aspose.cad.fileformats.cad.cadobjects/cadmaterial/).
Управляет тем, какой набор свойств материала используется рендерером.

```csharp
public enum CadMaterialMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Realistic | `0` | Режим физически‑корректного рендеринга. Использует упрощённую, физически правильную модель освещения. |
| Advanced | `1` | Продвинутый режим рендеринга. Предоставляет полный контроль над всеми свойствами материалов. |

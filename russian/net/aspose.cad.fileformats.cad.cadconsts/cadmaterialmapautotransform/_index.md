## CadMaterialMapAutoTransform enumeration

Указывает метод автоматического преобразования для [`CadMaterialMap`](../../../aspose.cad.fileformats.cad.cadobjects/cadmaterialmap/).

```csharp
[Flags]
public enum CadMaterialMapAutoTransform : byte
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Inherit | `0` | Наследовать настройку автоматического преобразования от родителя. |
| None | `1` | Автоматическое преобразование не применяется. |
| TransformObject | `2` | Умножить преобразование маппера на преобразование, которое масштабирует границы текущего объекта и переносит его в начало координат текущего объекта |
| Model | `4` | Умножить преобразование маппера на преобразование модели (блока). |

## ValidationMode enumeration

Определяет режимы проверки при чтении файлов.

```csharp
public enum ValidationMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Skip | `0` | Полностью пропускает проверку. |
| TryFix | `1` | В некоторых конкретных случаях файл может быть исправлен, и тогда успешно исправленные ошибки будут сообщаться как предупреждения. |
| Strict | `2` | Полная проверка, любая ошибка вызывает исключение. |


| Параметр | Тип | Описание |

### Возвращаемое значение

Значение, указывающее относительный порядок сравниваемых объектов. Возвращаемое значение имеет следующие значения: Значение Описание Меньше нуля Этот экземпляр предшествует *other* в порядке сортировки. Ноль Этот экземпляр находится в той же позиции в порядке сортировки, что и *other*. Больше нуля Этот экземпляр следует за *other* в порядке сортировки.

## AnimatableProperty<T>.GetValueAt method

Вычисляет значение этого `AnimatableProperty` при заданном *offset* для заданного *track*.

```csharp
public T GetValueAt(string track, float offset)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| трек | String | Имя трека анимации, или null. |
| offset | Single | Временное смещение внутри указанного трека анимации. |

### Возвращаемое значение

Вычисленное значение, полученное из анимационного *track*, или `Value`, если трек не найден.

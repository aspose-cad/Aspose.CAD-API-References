## CadGradientBackground.Height property

Получает значение, представляющее процент второго цвета в трехцветном градиенте.

```csharp
public double Height { get; }
```

### Property Value

Значение `Double`, представляющее процент второго цвета в трёхцветном градиенте.

## Примечания

Если значение равно 0, результатом будет двухцветный градиент, использующий цвета Top и Bottom.

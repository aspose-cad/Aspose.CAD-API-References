## RuntimeOptions.IsolateMemory property

True, если мы хотим копировать данные буферов вместо их совместного использования.

```csharp
public bool IsolateMemory { get; set; }
```

## Примечания

Если мы хотим создать рантайм‑представление модели, чтобы сборщик мусора освободил исходную модель,
нам нужно установить это значение в true, чтобы не использовать ссылки на исходную модель.

## Resources class

The resources.
 The [Canvas](../canvas/) and [FixedPage](../fixedpage/) elements can carry a resource dictionary.
 A resource dictionary is expressed in markup by the [FixedPage](../fixedpage/).Resources or [Canvas](../canvas/).Resources property element.
 Individual resource values MUST be specified within a resource dictionary.

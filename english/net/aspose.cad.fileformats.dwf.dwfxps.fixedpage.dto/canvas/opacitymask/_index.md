## Canvas.OpacityMask property

Gets or sets the opacity mask.
 Specifies a mask of alpha values that is applied to the canvas
 in the same fashion as the Opacity attribute,
 but allowing different alpha values for different areas of the element.

```csharp
public string OpacityMask { get; set; }
```

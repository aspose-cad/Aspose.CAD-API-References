## CadMaterialIlluminationModel enumeration

Determines the shader used to render a [`CadMaterial`](../../../aspose.cad.fileformats.cad.cadobjects/cadmaterial/).
 The shader affects the color of light reflected from the material's surface.

```csharp
public enum CadMaterialIlluminationModel
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| BlinnShader | `0` | Blinn shader. Reflected light color matches the light source color. |
| MetalShader | `1` | Metal shader. Reflected light color is a mix of the light source color and the material's diffuse color. |

## CadMaterialMapProjection enumeration

Specifies the texture projection method for a [`CadMaterialMap`](../../../aspose.cad.fileformats.cad.cadobjects/cadmaterialmap/).

```csharp
public enum CadMaterialMapProjection : byte
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Inherit | `0` | Inherit the projection from the parent. |
| Planar | `1` | Maps 2D image coordinates directly to XY coordinates. |
| Box | `2` | Maps 2D image coordinates to plane normal to major axis. |
| Cylinder | `3` | Maps 2D image coordinates to cylinder along Z axis. |
| Sphere | `4` | Maps 2D image coordinates to sphere with poles on Z axis. |

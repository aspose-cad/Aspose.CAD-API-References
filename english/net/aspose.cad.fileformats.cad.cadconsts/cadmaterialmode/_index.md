## CadMaterialMode enumeration

Determines the rendering mode of a [`CadMaterial`](../../../aspose.cad.fileformats.cad.cadobjects/cadmaterial/).
 Controls which set of material properties is used by the renderer.

```csharp
public enum CadMaterialMode
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Realistic | `0` | Physically-based rendering mode. Uses a simplified, physically correct shading model. |
| Advanced | `1` | Advanced rendering mode. Provides full control over all material properties. |

## CadMaterialMapSource enumeration

Specifies the texture source for a [`CadMaterialMap`](../../../aspose.cad.fileformats.cad.cadobjects/cadmaterialmap/).

```csharp
public enum CadMaterialMapSource : byte
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| Scene | `0` | The current rendered scene is used as the texture source. |
| File | `1` | An external image file is used as the texture source. |
| Procedural | `2` | A procedurally generated texture is used as the source. |

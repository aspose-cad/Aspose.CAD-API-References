## CadEntityBase.LType property

Gets or sets a value the current linetype of the entity.

```csharp
public byte LType { get; set; }
```

### Property Value

0 - ByLayer,

 1 - ByBlock,

 2 - Continuous,

 3 - Set based on `LTYPE` object

## Remarks

This property is always 0 for versions earlier than `AC1015`.

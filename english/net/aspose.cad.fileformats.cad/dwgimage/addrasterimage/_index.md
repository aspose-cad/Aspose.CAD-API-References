## DwgImage.AddRasterImage method

Adds a raster IMAGE entity to the drawing.

```csharp
public void AddRasterImage(string imagePath, Cad3DPoint insertPoint = null, double scale = 1m, 
    short rotation = 0, short brigtness = 50, short contrast = 50, short fade = 0)
```

| Parameter | Type | Description |
| --- | --- | --- |
| imagePath | String | Path to the raster image file. |
| insertPoint | Cad3DPoint | Insertion point of the image. |
| scale | Double | Uniform image scale factor. |
| rotation | Int16 | Image rotation angle in degrees (counter-clockwise). |
| brigtness | Int16 | Image brightness value in range [0..100]. |
| contrast | Int16 | Image contrast value in range [0..100]. |
| fade | Int16 | Image fade value in range [0..100]. |

## PageSizingOptions.Zoom property

This is a scaling factor to make drawing a bit smaller to fit vertical and horizontal lines into canvas.
 Default value is 1 - (0.0026 * 2) because during ZOOM EXTENTS command in Autocad it leaves about 0.26% from each side as a gap.

## ImageGlb.AlternateWriteFileName property

当设置为文件名或相对文件路径时，
它将用作写入的纹理的文件名。

当为 null 时，将使用默认文件名。

```csharp
public string AlternateWriteFileName { get; set; }
```

## 备注

如果不确定图像扩展名，使用 .* 作为扩展名将进行替换
在写入时将扩展名替换为适当的扩展名。
 
 

对于更高级的场景，您也可以使用：`ImageWriteCallback`

```csharp
public float IndexOfRefraction { get; set; }
```

## 备注

折射率 (IOR) 是一个测量得到的物理数值，通常在 1 到 2 之间。
它决定光线进入材料时弯曲或折射的程度。
它还影响反射光与透射光的比例，该比例由菲涅尔方程计算得出。
 
 

此属性支持 KHR_Materials_IOR 扩展。

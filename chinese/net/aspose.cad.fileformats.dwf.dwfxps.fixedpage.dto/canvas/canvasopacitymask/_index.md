## Canvas.CanvasOpacityMask property

获取或设置画布不透明度掩码。
指定一组 alpha 值的掩码，以与 Opacity 属性相同的方式应用于画布，
但允许对元素的不同区域使用不同的 alpha 值。

```csharp
public Brush CanvasOpacityMask { get; set; }
```

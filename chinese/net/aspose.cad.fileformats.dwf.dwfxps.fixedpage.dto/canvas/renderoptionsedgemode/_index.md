## Canvas.RenderOptionsEdgeMode property

获取或设置渲染选项边缘模式。
控制画布内路径的边缘如何渲染。
唯一有效的值是 Aliased。
省略此属性会导致边缘以使用者的默认方式渲染。

```csharp
public EdgeMode RenderOptionsEdgeMode { get; set; }
```

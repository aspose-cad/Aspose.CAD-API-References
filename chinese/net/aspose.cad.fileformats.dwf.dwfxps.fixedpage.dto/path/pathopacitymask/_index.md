## Path.PathOpacityMask property

获取或设置路径不透明度遮罩。
指定以与 Opacity 属性相同方式应用于路径的 alpha 值遮罩，
但允许对元素的不同区域使用不同的 alpha 值。

```csharp
public Brush PathOpacityMask { get; set; }
```

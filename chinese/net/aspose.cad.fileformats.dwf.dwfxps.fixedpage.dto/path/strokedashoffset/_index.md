## Path.StrokeDashOffset property

获取或设置描边虚线偏移。
调整重复虚线数组模式的起始点。
如果省略此值，虚线数组将与描边的原点对齐。
值以描边粗细的倍数指定。

```csharp
public double StrokeDashOffset { get; set; }
```

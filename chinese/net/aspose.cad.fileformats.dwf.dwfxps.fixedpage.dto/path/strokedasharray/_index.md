## Path.StrokeDashArray property

获取或设置笔画虚线数组。
指定轮廓笔画的短划线和间隙的长度。
这些值以笔画粗细的倍数指定
作为以空格分隔的列表，包含偶数个非负值。
绘制笔画时，这些指定的短划线和间隙
值会重复以覆盖笔画的长度。
如果省略此属性，笔画将实线绘制，不会有任何间隙。

```csharp
public string StrokeDashArray { get; set; }
```

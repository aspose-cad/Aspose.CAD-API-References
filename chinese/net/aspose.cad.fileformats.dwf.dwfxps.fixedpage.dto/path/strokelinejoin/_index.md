## Path.StrokeLineJoin property

获取或设置笔画线段连接方式。
指定在路径拐角处如何绘制笔画。
有效值为 Miter、Bevel 和 Round。
如果选择 Miter，则在绘制笔画时使用 StrokeMiterLimit 的值。

public LineJoin StrokeLineJoin { get; set; }

## DashCap enumeration

该虚线端帽。
正在描边的路径的有效渲染变换被使用
用于转换虚线轮廓的控制点。

```csharp
public enum DashCap
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Flat | `0` | 平直端帽。虚线的长度是指在曲线上，虚线结束的平直线与形状轮廓的两个交点之间的近似距离。一个虚线的结束点到下一个虚线起始点的距离为指定的虚线间隙长度。长度大于 0 的虚线会被绘制，长度为 0 的退化虚线则不会绘制。 |
| Round | `1` | 圆形端帽。虚线的长度是指在曲线上，两个轮廓交点之间的近似距离，即虚线结束的平直线（未附加圆形端帽）与形状轮廓的交点。端帽绘制为附着在虚线两端的半圆。圆形端帽的边界不会随轮廓而变形，而是通过有效渲染变换进行转换。相邻虚线的轮廓交点之间的距离为指定的虚线间隙长度。长度为 0 的退化虚线将绘制为圆形。 |
| Square | `2` | 方形端帽。虚线的长度是指在曲线上，两个轮廓交点之间的近似距离，即虚线结束的平直线（未附加方形端帽）与形状轮廓的交点。端帽绘制为附着在虚线两端的半方形。方形端帽的边界不会随轮廓弯曲，而是通过有效渲染变换进行转换。相邻虚线的轮廓交点之间的距离为指定的虚线间隙长度。长度为 0 的退化虚线将绘制为方形。如果长度为 0 的虚线出现在路径的连接处或非常接近连接处，渲染分辨率的差异以及坐标计算精度的差异可能导致不同消费者之间的端帽方向不同。 |
| Triangle | `3` | 三角形端帽。虚线的长度是指在曲线上，两个轮廓交点之间的近似距离，即虚线结束的平直线（未附加三角形端帽）与形状轮廓的交点。端帽绘制为底部贴合虚线两端的三角形。三角形端帽的边界不会随轮廓而变形，而是通过有效渲染变换进行转换。三角形的高度为描边宽度的一半。相邻虚线的轮廓交点之间的距离为指定的虚线间隙长度。长度为 0 的退化虚线将绘制为菱形。如果长度为 0 的虚线出现在路径的连接处或非常接近连接处，渲染分辨率的差异以及坐标计算精度的差异可能导致不同消费者之间的端帽方向不同。 |

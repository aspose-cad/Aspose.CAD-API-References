## LinearGradientBrush.LinearGradientBrushTransform property

获取或设置线性渐变画刷变换。
描述应用于画刷坐标空间的矩阵变换。
Transform 属性会与当前有效的渲染进行串联
变换，以产生相对于画笔的有效渲染变换。
起点和终点使用本地有效渲染变换进行转换。

```csharp
public Transform LinearGradientBrushTransform { get; set; }
```

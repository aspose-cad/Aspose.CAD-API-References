## LinearGradientBrush.EndPoint property

获取或设置终点。
指定线性渐变的终点。
线性渐变画刷对颜色进行插值，从
起点到终点，其中起点
表示偏移量 0，且 EndPoint 表示偏移量 1。
在 GradientStop 元素中指定的 Offset 属性值
与起点和终点定义的 0 和 1 偏移量相关。

```csharp
public string EndPoint { get; set; }
```

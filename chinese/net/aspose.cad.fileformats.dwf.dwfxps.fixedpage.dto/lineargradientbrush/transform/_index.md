## LinearGradientBrush.Transform property

获取或设置变换。
描述应用于画刷坐标空间的矩阵变换。
画刷上的 Transform 属性会与当前有效的
渲染变换相连接，以产生相对于画刷的有效渲染变换。
起点和终点使用本地有效渲染变换进行转换。

```csharp
public string Transform { get; set; }
```

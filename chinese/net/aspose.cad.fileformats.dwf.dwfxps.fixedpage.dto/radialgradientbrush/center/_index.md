## RadialGradientBrush.Center property

获取或设置中心。
指定径向渐变的中心点（即椭圆的中心）。
径向渐变画刷在渐变原点和椭圆的周长之间插值颜色。
周长由中心和半径决定。

public string Center { get; set; }

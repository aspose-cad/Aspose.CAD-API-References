## RadialGradientBrush.Transform property

获取或设置变换。
描述应用于画刷坐标空间的矩阵变换。
Transform 属性与当前有效的渲染变换进行串联
以产生相对于画笔的有效渲染变换。
由中心、渐变起点、x 半径定义的椭圆，
以及 y 半径值使用本地有效渲染变换进行转换。

```csharp
public string Transform { get; set; }
```

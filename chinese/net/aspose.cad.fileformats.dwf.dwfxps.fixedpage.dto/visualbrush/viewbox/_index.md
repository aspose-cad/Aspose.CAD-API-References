## VisualBrush.Viewbox property

获取或设置视图框。
指定画刷源内容的位置和尺寸。
指定四个以逗号分隔的实数 (x, y, Width, Height)，其中宽度和高度为非负数。
视图框定义了在 VisualBrush.Visual 属性元素中指定的元素的默认坐标系。
视图框的四角映射到视口的四角，从而为画刷的源内容提供默认的裁剪和变换。

```csharp
public string Viewbox { get; set; }
```

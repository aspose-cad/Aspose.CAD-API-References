## VisualBrush.Opacity property

获取或设置不透明度。
定义画笔填充的统一透明度。
值的范围从 0（完全透明）到 1（完全不透明），
包括在内。超出此范围的值无效。

```csharp
public double Opacity { get; set; }
```

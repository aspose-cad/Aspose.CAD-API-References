## VisualBrush.VisualBrushTransform property

获取或设置视觉画刷的变换。
描述应用于画刷坐标空间的矩阵变换。
Transform 属性与当前有效的渲染变换连接，以产生相对于画刷的有效渲染变换。
使用局部有效的渲染变换对画刷的视口进行变换。

```csharp
public Transform VisualBrushTransform { get; set; }
```

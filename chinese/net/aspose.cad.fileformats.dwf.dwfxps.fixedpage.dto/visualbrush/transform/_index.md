## VisualBrush.Transform property

获取或设置变换。
描述应用于画刷坐标空间的矩阵变换。
Transform 属性与当前有效的渲染变换连接，以产生相对于画刷的有效渲染变换。
画笔的视口使用该局部有效渲染变换进行转换。

```csharp
public string Transform { get; set; }
```

## FixedPage.BleedBox property

获取或设置出血框。
指定 ContentBox 与所有预期出现在最终打印的图形内容的边界框的并集
以及裁剪页面。包含四个坐标值的列表（BleedOriginX、BleedOriginY、BleedWidth、BleedHeight），
以逗号分隔的实数表示。如果省略，默认值为 (0,0, Width, Height)。

```csharp
public string BleedBox { get; set; }
```

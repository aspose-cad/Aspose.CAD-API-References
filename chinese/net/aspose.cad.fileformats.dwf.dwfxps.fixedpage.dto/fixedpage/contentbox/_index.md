## FixedPage.ContentBox property

获取或设置内容框。
指定页面中包含图像内容的区域，以适配到图像区域内
在打印或查看时。包含四个坐标值的列表（ContentOriginX、ContentOriginY、ContentWidth、ContentHeight），
以逗号分隔的实数表示。建议指定该值。如果省略，默认值为 (0,0,Width,Height)。

```csharp
public string ContentBox { get; set; }
```

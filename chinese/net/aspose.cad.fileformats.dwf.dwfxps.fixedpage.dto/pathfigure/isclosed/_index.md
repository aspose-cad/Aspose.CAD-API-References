## PathFigure.IsClosed property

获取或设置一个值，指示是否闭合。
指定路径是否闭合。
如果设置为 true，笔画将被绘制为“闭合”，即，
路径图形最后一段的最后一点将与
StartPoint 属性中指定的点相连，
否则笔画将被绘制为“开放”，且最后一点不与起始点相连。
仅在路径图形用于指定笔画的 Path 元素时适用。

```csharp
public bool IsClosed { get; set; }
```

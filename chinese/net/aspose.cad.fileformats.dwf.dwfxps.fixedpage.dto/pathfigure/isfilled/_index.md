## PathFigure.IsFilled property

获取或设置一个值，指示是否已填充。
指定路径图形是否用于计算面积
包含的路径几何体。
可以为 true 或 false。
当设置为 false 时，路径图形仅用于描边。

```csharp
public bool IsFilled { get; set; }
```

## Glyphs.RenderTransform property

获取或设置渲染变换。
为由 Glyphs 元素指定的字形运行建立新的坐标框架。
渲染变换影响裁剪、透明度蒙版、填充、x 原点、y 原点以及各个字形的实际形状，
以及前进宽度。渲染变换还影响字体大小以及在 Indices 属性中指定的值。

```csharp
public string RenderTransform { get; set; }
```

## Glyphs.BidiLevel property

获取或设置 BIDI 级别。
指定 Unicode 算法的双向嵌套级别。
偶数值表示从左到右布局，奇数值表示从右到左布局。
从右到左布局将运行起点放置在第一个字形的右侧，
使用正的前进宽度（表示向左的前进）
将后续字形放置在前一个字形的左侧。有效值范围为 0 到 61（含）。

public string BidiLevel { get; set; }

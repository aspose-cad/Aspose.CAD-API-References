## Glyphs.UnicodeString property

获取或设置 Unicode 字符串。
包含由 Glyphs 元素渲染的文本字符串。
文本以 Unicode 码点的形式指定。
如果未指定 Glyphs 元素的 UnicodeString 属性
或包含空值（“” 或 “{ }”），且未指定 Indices 属性
或不包含字形索引，则消费者必须触发错误条件。

```csharp
public string UnicodeString { get; set; }
```

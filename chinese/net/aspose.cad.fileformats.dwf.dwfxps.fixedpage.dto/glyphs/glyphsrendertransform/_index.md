## Glyphs.GlyphsRenderTransform property

获取或设置字形渲染变换。
为由 Glyphs 元素指定的字形运行建立新的坐标框架。
渲染变换会影响裁剪、透明度掩码、填充、x 原点、y 原点、各个字形的实际形状以及前进宽度。
渲染变换还会影响字体大小以及在 Indices 属性中指定的值。

```csharp
public Transform GlyphsRenderTransform { get; set; }
```

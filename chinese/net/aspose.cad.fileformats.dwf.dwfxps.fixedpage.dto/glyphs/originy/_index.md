## Glyphs.OriginY property

获取或设置原点 Y。
指定运行中第一个字形的 Y 坐标，单位为有效坐标空间。
字形放置的位置使其前进向量的前缘与基线相交
与 OriginX 和 OriginY 属性定义的点相对应。

public double OriginY { get; set; }

## Glyphs.FontUri property

获取或设置字体 URI。
运行中所有字形所使用的物理字体的 URI。该 URI 必须引用包中包含的字体。
如果引用的物理字体是 TrueType 集合（包含多个字体面），
URI 的片段部分是一个从 0 开始的索引，指示应使用 TrueType 集合中的哪个字体面。

public string FontUri { get; set; }

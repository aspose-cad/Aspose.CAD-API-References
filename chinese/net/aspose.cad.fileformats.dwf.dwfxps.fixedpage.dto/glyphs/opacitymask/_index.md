## Glyphs.OpacityMask property

获取或设置透明度蒙版。
指定一组 alpha 值的蒙版，以与 Opacity 属性相同的方式应用于字形，
但允许对元素的不同区域使用不同的 alpha 值。

```csharp
public string OpacityMask { get; set; }
```

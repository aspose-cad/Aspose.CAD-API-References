## Glyphs.Indices property

获取或设置索引。
指定用于渲染字形序列的一系列字形索引及其属性。
如果未指定 Glyphs 元素的 UnicodeString 属性
或包含空值（“” 或 “{ }”），且如果未指定 Indices 属性或其中不包含任何字形索引，
那么，消费者必须实例化一个错误条件。

```csharp
public string Indices { get; set; }
```

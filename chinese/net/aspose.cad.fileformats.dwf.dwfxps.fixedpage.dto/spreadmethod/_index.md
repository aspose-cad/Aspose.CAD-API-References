## SpreadMethod enumeration

扩展方法。
描述画笔应如何填充主（初始）渐变区域之外的内容区域。

```csharp
public enum SpreadMethod
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Pad | `0` | 填充（pad）。在此方法中，使用第一种颜色和最后一种颜色分别填充起始和结束的剩余填充区域。 |
| Reflect | `1` | 反射（reflect）。在此方法中，梯度停靠点以相反顺序重复播放，以覆盖填充区域。 |
| Repeat | `2` | 重复（repeat）。在此方法中，梯度停靠点按顺序重复，直至填充区域被覆盖。 |

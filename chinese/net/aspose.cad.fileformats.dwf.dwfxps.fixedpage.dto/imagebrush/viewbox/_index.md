## ImageBrush.Viewbox property

获取或设置视图框。
指定画刷源内容的位置和尺寸。
指定四个以逗号分隔的实数 (x, y, width, height)，
其中宽度和高度为非负数。
指定的尺寸相对于图像的物理尺寸，以 1/96\" 为单位。
视口的四个角映射到视图窗口的四个角，
从而为画笔的源内容提供默认的裁剪和变换。

public string Viewbox { get; set; }

## ImageBrush.Viewport property

获取或设置视口。
指定包含坐标空间中的区域
主画笔瓦片（可能会重复）应用的
以填充画笔所应用的区域。
指定四个以逗号分隔的实数（x、y、宽度、高度），
其中宽度和高度为非负数。对齐方式为
通过调整 x 和 y 值来控制画笔图案。

```csharp
public string Viewport { get; set; }
```

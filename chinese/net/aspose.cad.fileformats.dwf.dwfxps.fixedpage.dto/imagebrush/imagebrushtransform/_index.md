## ImageBrush.ImageBrushTransform property

获取或设置图像画刷的变换。
描述应用于画刷坐标空间的矩阵变换。
Transform 属性会与当前有效的渲染进行串联
变换，以产生相对于画笔的有效渲染变换。
使用局部有效的渲染变换对画刷的视口进行变换。

```csharp
public Transform ImageBrushTransform { get; set; }
```

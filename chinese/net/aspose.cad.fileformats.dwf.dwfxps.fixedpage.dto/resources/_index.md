## Resources class

这些资源。
The [Canvas](../canvas/) 和 [FixedPage](../fixedpage/) 元素可以携带资源字典。
资源字典在标记中通过 [FixedPage](../fixedpage/).Resources 或 [Canvas](../canvas/).Resources 属性元素表示。
必须在资源字典中指定各个资源值。

public class Resources

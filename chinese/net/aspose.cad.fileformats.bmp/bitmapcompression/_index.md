## BitmapCompression enumeration

指定不同的位图压缩方法。

```csharp
public enum BitmapCompression : uint
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Rgb | `0` | 无压缩。 |
| Rle8 | `1` | RLE 8 位/像素压缩。只能用于 8 位/像素 位图。 |
| Rle4 | `2` | RLE 4 位/像素压缩。只能用于 4 位/像素 位图。 |
| Bitfields | `3` | RGB 位字段。只能用于 16 位和 32 位/像素 位图。 |
| Jpeg | `4` | JPEG 压缩。该位图包含 JPEG 图像。 |
| Png | `5` | PNG 压缩。该位图包含 PNG 图像。 |
| AlphaBitfields | `6` | RGBA 位字段。只能用于 16 位和 32 位/像素 位图。 |
| Dxt1 | `827611204` | DXT1 压缩。该位图包含纹理。 |

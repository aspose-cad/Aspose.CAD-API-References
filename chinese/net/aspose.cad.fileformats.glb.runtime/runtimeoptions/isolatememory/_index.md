## RuntimeOptions.IsolateMemory property

如果我们想复制缓冲区数据而不是共享它，则为 True。

```csharp
public bool IsolateMemory { get; set; }
```

## 备注

如果我们想创建模型的运行时表示，以便垃圾收集器释放源模型，
我们必须将其设置为 true，这样就不会使用任何对源模型的引用。

## LightBuilder.Spot.Range property

获取或设置一个提示，定义距离阈值，在此处
光的强度可视为已达到零。

仅支持点光源和聚光灯。必须 &gt; 0。

当未定义时，范围被视为无限。

```csharp
public float Range { get; set; }
```

## LightBuilder.Intensity property

获取或设置光的亮度。

此定义的单位取决于光的类型。

点光和聚光灯使用坎德拉 (lm/sr) 的光强度
而方向光使用勒克斯 (lm/m2) 的照度

```csharp
public float Intensity { get; set; }
```

## CadGradientBackground.Height property

获取表示三色渐变中第二种颜色百分比的值。

```csharp
public double Height { get; }
```

### Property Value

一个 `Double` 值，表示三色梯度中第二种颜色的百分比。

## 备注

如果该值为 0，结果将是使用顶部和底部颜色的两色梯度。

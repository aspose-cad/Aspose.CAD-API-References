## CadEntityBase.IsByLayer property

获取或设置一个值，指示实体的线型是否由图层设置。

```csharp
public bool IsByLayer { get; set; }
```

### Property Value

`true` 如果实体的线型按图层设置。

## 备注

此标志始终为 false，除版本 `AC1012` 和 `AC1014` 外。

## CadEntityBase.LType property

获取或设置实体当前线型的值。

```csharp
public byte LType { get; set; }
```

### Property Value

0 - 按图层,

1 - 按块,

2 - 连续,

3 - 根据 `LTYPE` 对象设置

## 备注

对于早于 `AC1015` 的版本，此属性始终为 0。

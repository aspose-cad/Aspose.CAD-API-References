## CadEntityBase.PlotStyleFlag property

获取或设置实体当前打印样式的值。

```csharp
public byte PlotStyleFlag { get; set; }
```

### Property Value

0 - 按图层,

1 - 按块,

3 - 根据 `PLACEHOLDER` 对象设置

## 备注

对于早于 `AC1015` 的版本，此属性始终为 0。

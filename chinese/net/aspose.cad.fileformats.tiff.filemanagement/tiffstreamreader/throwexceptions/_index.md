## TiffStreamReader.ThrowExceptions property

获取或设置一个值，指示在数据处理错误（读取或写入流）时是否抛出异常。

```csharp
public bool ThrowExceptions { get; set; }
```

### Property Value

`true` 如果在错误的数据处理时抛出异常；否则，错误条件将被静默忽略。

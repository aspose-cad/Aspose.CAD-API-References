## Overview

该命名空间包含与 Psd 相关的资源元素。

是 [Aspose.CAD for .NET](../) API 参考的一部分。

## 类

| 类 | 描述 |
| --- | --- |
| [GridAndGuidesResouce](./gridandguidesresouce/) | 表示网格和参考线资源。 |
| [Thumbnail4Resource](./thumbnail4resource/) | 表示 PSD 4.0 的缩略图资源。 |
| [ThumbnailResource](./thumbnailresource/) | 缩略图资源块。 |
| [TransparencyIndexResource](./transparencyindexresource/) | 透明度索引资源块。 |
| [UnknownResource](./unknownresource/) | 未知资源。当资源块未被识别时，将创建此资源块。 |
| [XmpResouce](./xmpresouce/) | 表示 XMP 元数据资源。 |

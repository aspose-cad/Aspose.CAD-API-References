## PngColorType enumeration

表示 PNG 图像的颜色类型。

```csharp
public enum PngColorType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Grayscale | `0` | 表示每个像素为灰度样本的颜色类型。 |
| Truecolor | `2` | 表示每个像素为 R,G,B 三元组的颜色类型。 |
| IndexedColor | `3` | 表示每个像素为调色板索引的颜色类型；应出现 PLTE 块。 |
| GrayscaleWithAlpha | `4` | 表示颜色类型，其中每个像素是灰度采样，随后是 alpha 采样。 |
| TruecolorWithAlpha | `6` | 表示颜色类型，其中每个像素是 R,G,B 三元组，随后是 alpha 采样。 |

## AnimatableProperty<T>.GetValueAt method

在给定的 *offset* 和给定的 *track* 上评估此 `AnimatableProperty` 的值。

```csharp
public T GetValueAt(string track, float offset)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 轨道 | String | 动画轨道名称，或为 null。 |
| offset | Single | 给定动画轨道内的时间偏移。 |

### 返回值

从动画 *轨道* 获取的评估值，如果未找到轨道，则为 `Value`。

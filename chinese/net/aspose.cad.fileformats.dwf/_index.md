## Overview

该命名空间包含 DWF 图形文件处理的类和方法。

是 [Aspose.CAD for .NET](../) API 参考的一部分。

## 类

| 类 | 描述 |
| --- | --- |
| [DwfImage](./dwfimage/) | DWF 图像类。提供对 DWF/DWFX 格式文件的读取、处理以及导出为其他格式的功能。 |
| [DwfLayersList](./dwflayerslist/) | 图层表列表 |
| [DwfLoadOptions](./dwfloadoptions/) | 表示 DWF 图像的加载选项。 |
| [DwfMergeOptions](./dwfmergeoptions/) | DWF 合并选项。 |
| [DwfMetadata](./dwfmetadata/) | 用于存储 Dwf/Dwfx 文件中元数据和页面描述符集合中单个记录单元信息的类。 |
| [DwfPage](./dwfpage/) | 表示 DWF 页面基础类。 |

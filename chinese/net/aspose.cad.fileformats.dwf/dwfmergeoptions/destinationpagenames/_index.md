## DwfMergeOptions.DestinationPageNames property

获取或设置目标 DWF 图像的页面名称，以便在其上添加光栅覆盖图像。
如果未设置，光栅覆盖图像将添加到所有页面。

```csharp
public string[] DestinationPageNames { get; set; }
```

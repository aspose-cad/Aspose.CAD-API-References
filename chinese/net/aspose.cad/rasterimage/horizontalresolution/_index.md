## RasterImage.HorizontalResolution property

获取或设置此 [`RasterImage`](../) 的水平分辨率（每英寸像素数）。

```csharp
public virtual double HorizontalResolution { get; set; }
```

### Property Value

水平分辨率。

## 备注

注意：默认情况下此值始终为 96，因为不同平台无法返回屏幕分辨率。您可以考虑使用 SetResolution 方法在一次调用中更新两个分辨率值。

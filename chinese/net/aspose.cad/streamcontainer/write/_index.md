## Write(byte[], int, int) {#write_1}

将一系列字节写入当前流，并将此流内的当前位置前移写入的字节数。

```csharp
public virtual void Write(byte[] buffer, int offset, int count)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| buffer | Byte[] | 字节数组。此方法将 *count* 字节从 *buffer* 复制到当前流。 |
| offset | Int32 | 在 *buffer* 中的基于零的字节偏移量，指示从何处开始将字节复制到当前流。 |
| 计数 | Int32 | 要写入当前流的字节数。 |

## PixelDataFormat Equality operator

返回两个 [`PixelDataFormat`](../) 类的相等性结果。

```csharp
public static bool operator ==(PixelDataFormat pixelFormat1, PixelDataFormat pixelFormat2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| pixelFormat1 | PixelDataFormat | 第一个用于比较的 `PixelDataFormat`。 |
| pixelFormat2 | PixelDataFormat | 第二个用于比较的 `PixelDataFormat`。 |

### 返回值

如果 *pixelFormat1* 和 *pixelFormat2* 都包含相等的数据，或两个参数均为 null，则返回 True。

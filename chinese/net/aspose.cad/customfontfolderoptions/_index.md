## CustomFontFolderOptions enumeration

自定义字体文件夹指定的选项。

```csharp
public enum CustomFontFolderOptions
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| AddFolderForSingleFile | `0` | 为此单个文件将指定的文件夹添加到默认字体文件夹中 |
| AddFolderForAll | `1` | 为所有文件将指定的文件夹添加到默认字体文件夹中 |
| ReplaceFolderForSingleFile | `2` | 仅对该单个文件使用指定的字体文件夹（不包括默认文件夹） |
| ReplaceFolderForAll | `3` | 仅对该单个文件使用指定的字体文件夹（不包括默认文件夹） |

## Matrix.TypeGeneralRotation field

此标志位指示此对象定义的变换
执行任意角度的旋转之外，还会进行
其他标志位指示的转换。
旋转会以相同的量改变向量的角度
无论向量的原始方向如何，且不
更改向量的长度。
此标志位与该标志位互斥

```csharp
public const int TypeGeneralRotation;
```

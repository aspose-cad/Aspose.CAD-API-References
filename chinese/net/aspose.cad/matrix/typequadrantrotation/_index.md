## Matrix.TypeQuadrantRotation field

此标志位指示此对象定义的变换
执行以 90 度为倍数的象限旋转
此外，还会进行其他标志位指示的转换。
旋转会以相同的量改变向量的角度
无论向量的原始方向如何，且不
更改向量的长度。
此标志位与 TypeGeneralRotation 标志互斥。

```csharp
public const int TypeQuadrantRotation;
```

## Matrix.TypeFlip field

此标志位指示此对象定义的变换
在某个轴上执行镜像翻转，从而改变
通常的右手坐标系变为左手坐标系
系统，此外还包括其他标志位指示的转换。
右手坐标系是指正 X 轴
轴逆时针旋转以覆盖正 Y 轴
类似于右手手指的方向
当你正对拇指时，手指的卷曲方向。
左手坐标系是指正 X
轴顺时针旋转，以覆盖正 Y 轴，类似
朝向左手手指弯曲的方向。
没有数学方法可以确定该角度的
原始翻转或镜像变换，因为所有角度
翻转的角度在给定适当的调整旋转时是相同的。
注意：TypeFlip 是在 GENERAL_TRANSFORM 公开后添加的
循环且标志位不再能够方便地
重新编号而不会在外部引入二进制不兼容性
代码。

```csharp
public const int TypeFlip;
```

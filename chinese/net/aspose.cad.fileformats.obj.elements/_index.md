## Overview

该命名空间处理 Obj 文件格式的元素。

是 [Aspose.CAD for .NET](../) API 参考的一部分。

## 类

| 类 | 描述 |
| --- | --- |
| [ObjFace](./objface/) | 表示 OBJ 图像的面对象。它存储顶点、纹理和法线的索引。 |
| [ObjRoot](./objroot/) | 表示 OBJ 绘图的根信息。ObjRoot 包含关于顶点、材质和形状的数据。每个形状包含一组面的信息，以及相应的材质、顶点、纹理和法线索引。 |
| [ObjShape](./objshape/) | 表示 OBJ 格式的形状对象。包含一组面的信息，以及相应的材质、顶点、纹理和法线索引。 |

## Overview

该命名空间包含用于 STL 模型的类。

是 [Aspose.CAD for .NET](../) API 参考的一部分。

## 类

| 类 | 描述 |
| --- | --- |
| [ColorDataUnit](./colordataunit/) | 自定义表面的颜色。 |
| [NormalDataUnit](./normaldataunit/) | 表面的法向。 |
| [StlFace](./stlface/) | 表示 Stl 图像的面对象。它存储顶点、纹理和法线的索引。 |
| [StlRoot](./stlroot/) | 表示 STL 绘图的根信息。StlRoot 包含关于顶点、材质和形状的数据。每个形状包含一组面及其对应的材质、顶点和法线索引的信息。 |
| [StlShape](./stlshape/) | 表示 Stl 格式的形状对象。包含一组面及其对应的材质、顶点、纹理和法线索引的信息。 |
| [TriangularFacet](./triangularfacet/) | 表面的三角面片。 |
| [VertexDataUnit](./vertexdataunit/) | 顶点三角面片的坐标。 |

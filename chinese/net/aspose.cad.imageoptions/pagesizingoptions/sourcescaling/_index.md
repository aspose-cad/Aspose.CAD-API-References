## PageSizingOptions.SourceScaling property

在不考虑单位的情况下，源尺寸应放大多少。如果源是 1×1 英寸，且 SourceScaling = 10，则源被解释为 10×10 英寸。

```csharp
public double SourceScaling { get; set; }
```

## PageSizingOptions.Margins property

当前页面的边距大小。如果通过 Width\\Height\\Depth 显式提供输出页面大小，则从尺寸中减去边距。如果输出页面大小是根据源尺寸计算的，则会添加边距。

```csharp
public Margins Margins { get; set; }
```

## PageSizingOptions.OverrideOutputUnitType property

覆盖输出格式的测量单位。例如，PDF 的单位是点，等于英寸的 1/72。1×1 英寸的源将输出为 72×72 到 PDF。如果将 OverrideOutputUnitType 设置为 Inch，输出将为 1×1。

```csharp
public UnitType? OverrideOutputUnitType { get; set; }
```

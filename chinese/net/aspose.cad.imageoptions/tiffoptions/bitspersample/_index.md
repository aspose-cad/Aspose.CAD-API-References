## TiffOptions.BitsPerSample property

获取或设置每样本位数。

```csharp
public ushort[] BitsPerSample { get; set; }
```

### Property Value

每样本位数的值。

## 备注

设置此值时请注意，它还会将 SamplesPerPixel 的值设置为数组长度。这两个属性紧密耦合，因而只能一起设置。

## DxfOptions.ConvertMeshToLines property

获取或设置一个值，指示网格几何体（例如来自 DWF 的 3D 壳）是否应
导出为线（线框）而不是 MESH 实体，从而生成的 DXF 仅包含线。
默认启用：DWF 转 DXF 转换永不生成网格，除非此设置为 `false`。

```csharp
public bool ConvertMeshToLines { get; set; }
```

## VectorRasterizationOptions.EmbedBackground property

获取或设置是否应将与输出格式默认背景颜色不同的颜色背景（PDF 和 SVG 为白色，光栅为透明）嵌入输出图像（如果不嵌入，背景将使用输出渲染系统的默认值，但依赖背景颜色的内容将使用指定的背景颜色进行渲染）。

```csharp
public bool EmbedBackground { get; set; }
```

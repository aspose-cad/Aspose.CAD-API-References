## Scene class

该场景。
该场景体现了可以从 COLLADA 资源内容中可视化的全部信息。
该场景元素声明了场景层次结构或场景图的基础。
场景包含由创作工具生成的大部分视觉和变换信息内容的元素。

public class Scene : ColladaElement

## Tristrips.Material property

获取或设置材质。
material 属性声明一个材料的符号。
此符号在实例化时绑定到材料。
如果未指定 material 属性，则光照和阴影结果由应用程序定义。
可选属性。

```csharp
public string Material { get; set; }
```

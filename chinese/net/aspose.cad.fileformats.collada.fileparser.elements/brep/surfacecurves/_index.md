## Brep.SurfaceCurves property

获取或设置表面曲线。
包含此 B-rep 中使用的所有 2D 曲线。
这包括描述面类型的表面。
如果存在 faces 元素，则此元素是必需的。

```csharp
public SurfaceCurves SurfaceCurves { get; set; }
```

## GeographicLocation.Altitude property

获取或设置海拔。
海拔始终以米为单位。
如果模式为 "absolute"，则该值解释为相对于平均海平面的米数。
如果模式为 "relativeToGround"，则该值解释为该特定位置实际地面高程之上的米数。

```csharp
public Altitude Altitude { get; set; }
```

## Node.Layer property

获取或设置图层。
layer 属性指示此节点所属的图层名称。
例如，值为 "foreground glowing" 表示此节点同时属于 'foreground' 图层和 'glowing' 图层。
默认值为空，表示该节点不属于任何图层。
可选属性。

```csharp
public string[] Layer { get; set; }
```

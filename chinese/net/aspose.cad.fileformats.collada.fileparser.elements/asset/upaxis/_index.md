## Asset.UpAxis property

获取或设置上轴。
up_axis 元素包含关于几何数据坐标系的描述信息。
所有坐标系默认为右手坐标系。
此元素指定哪条轴被视为向上方向。
默认是 Y 轴。up_axis 元素可能出现零次或一次。

public EnumUpAxis UpAxis { get; set; }

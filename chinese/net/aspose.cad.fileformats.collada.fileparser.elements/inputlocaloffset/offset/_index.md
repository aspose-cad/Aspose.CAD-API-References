## InputLocalOffset.Offset property

获取或设置偏移量。
offset 属性表示在索引列表中的偏移。
如果两个输入元素共享相同的偏移，它们将被相同地索引。
这既是一种对索引列表的简单压缩形式，也定义了输入应使用的顺序。
必需属性。

```csharp
public ulong Offset { get; set; }
```

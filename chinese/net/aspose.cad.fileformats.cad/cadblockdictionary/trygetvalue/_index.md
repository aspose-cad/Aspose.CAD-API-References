## CadBlockDictionary.TryGetValue method

获取与指定键关联的值。

```csharp
public bool TryGetValue(string key, out CadBlockEntity value)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| key | String | 要获取其值的键。 |
| value | CadBlockEntity& | 当此方法返回时，如果找到该键，则返回与指定键关联的值；否则返回 *value* 参数类型的默认值。此参数以未初始化状态传递。 |

### 返回值

如果字典包含具有指定键的元素，则为 true；否则为 false。

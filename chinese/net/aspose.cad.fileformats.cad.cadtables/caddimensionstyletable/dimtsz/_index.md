## CadDimensionStyleTable.Dimtsz property

获取或设置线性、半径和直径标注的笔画和箭头的绘制模式。
如果值为 0，将绘制箭头，正值定义斜线的大小而不是箭头。
该值将乘以 Dimscale。

```csharp
public double Dimtsz { get; set; }
```

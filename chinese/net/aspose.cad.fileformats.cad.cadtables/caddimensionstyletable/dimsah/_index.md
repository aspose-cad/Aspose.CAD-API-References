## CadDimensionStyleTable.Dimsah property

获取或设置应使用的箭头块。
如果值为 0，则使用由 Dimblk 设置的箭头；如果值为 1，则使用来自 Dimblk1 和 Dimblk2 的箭头。

```csharp
public short Dimsah { get; set; }
```

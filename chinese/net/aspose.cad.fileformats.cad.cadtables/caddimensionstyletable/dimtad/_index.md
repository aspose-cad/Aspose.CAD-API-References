## CadDimensionStyleTable.Dimtad property

获取或设置文字相对于尺寸线的垂直位置模式。
可能的取值为：0（位于延伸线之间居中），1（位于尺寸线之上），
2（位于距离定义点最远的一侧），3（位置遵循日本工业标准（JIS）），
4（位于尺寸线之下）。

```csharp
public short Dimtad { get; set; }
```

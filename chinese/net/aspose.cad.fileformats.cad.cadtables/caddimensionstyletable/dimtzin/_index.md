## CadDimensionStyleTable.Dimtzin property

获取或设置公差值中零的抑制。
可能的取值为：0（抑制零英尺和精确零英寸），1（包括零英尺和精确零英寸），
2（包含零英尺并抑制零英寸），3（包含零英寸并抑制零英尺），
4（抑制前导零），8（抑制尾随零），12（同时抑制前导零和尾随零）。

```csharp
public short Dimtzin { get; set; }
```

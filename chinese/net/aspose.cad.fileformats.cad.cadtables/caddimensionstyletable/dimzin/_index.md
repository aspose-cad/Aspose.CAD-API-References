## CadDimensionStyleTable.Dimzin property

获取或设置主单位值中零的抑制。
可能的取值为：0（抑制零英尺并精确零英寸），1（包含零英尺并精确零英寸），
2（包含零英尺并抑制零英寸），3（包含零英寸并抑制零英尺），
4（位 3，抑制前导零），8（位 4，抑制尾随零），12（位 3 和位 4，抑制前导零和尾随零）。

```csharp
public short Dimzin { get; set; }
```

## CadDimensionStyleTable.Dimlim property

获取或设置尺寸限制作为默认文本。
可能的取值为：0（不生成默认文本的限制），1（生成默认文本的限制）。
如果此值为 1，则 Dimtol 值视为关闭。

```csharp
public short Dimlim { get; set; }
```

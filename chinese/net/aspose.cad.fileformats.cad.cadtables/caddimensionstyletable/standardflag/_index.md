## CadDimensionStyleTable.StandardFlag property

获取或设置标准标志的位编码值。
可能的取值为：16（表项外部依赖于外部参照），
32 和 16（外部依赖的外部参照已成功解析），
64（上次编辑图形时，表项至少被绘图中的一个实体引用）。

```csharp
public short StandardFlag { get; set; }
```

## CadDimensionStyleTable.Dimarcsym property

获取或设置用于显示弧长标注的弧符号模式。
可能的取值为：0（弧长符号位于标注文本之前），1（弧长符号位于
标注文本之后），2（弧长符号不显示）。

```csharp
public int Dimarcsym { get; set; }
```

### Property Value

用于显示弧长标注的弧符号模式。

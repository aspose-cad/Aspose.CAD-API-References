## CadDimensionStyleTable.Dimcen property

获取或设置绘制弧/圆中心标记和中心线的模式。
如果值为 0，则不绘制中心标记；如果为负，则绘制中心线；如果为正，则绘制中心标记。

public double Dimcen { get; set; }

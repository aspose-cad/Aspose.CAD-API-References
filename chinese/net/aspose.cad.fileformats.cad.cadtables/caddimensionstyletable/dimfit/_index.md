## CadDimensionStyleTable.Dimfit property

获取或设置 Dimatfit 和 Dimtmove 的组合。
如果此值在 0 ～ 3 范围内，则 Dimatfit 也设置为 0 ～ 3，且 Dumtmove 设置为 0。
如果此值为 4 或 5，则 Dimatfit 为 3，Dimtmove 为 1 或 2。

public short Dimfit { get; set; }

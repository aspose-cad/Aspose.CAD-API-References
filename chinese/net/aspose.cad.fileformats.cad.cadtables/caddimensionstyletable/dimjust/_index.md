## CadDimensionStyleTable.Dimjust property

获取或设置文本水平定位的模式。
可能的取值为：0（文本位于尺寸线之上并居中于延伸线之间），
1（文本位于第一条延伸线旁），2（文本位于第二条延伸线旁），
3（文本位于上方并与第一条延伸线对齐），4（文本位于上方并与第二条延伸线对齐）。

```csharp
public short Dimjust { get; set; }
```

## CadDimensionStyleTable.Dimtofl property

获取或设置即使文本放置在外部，也在延伸线之间绘制尺寸线的模式。
可能的取值为：0（不在测量点之间绘制尺寸线），
1（在测量点之间绘制尺寸线）。

```csharp
public short Dimtofl { get; set; }
```

## CadDimensionStyleTable.Dimdli property

获取或设置基线尺寸中尺寸线的间距。
如果需要，每条尺寸线会根据此值相对于前一条进行偏移，以避免绘制重叠。

```csharp
public double Dimdli { get; set; }
```
